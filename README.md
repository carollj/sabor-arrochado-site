# Sabor Arrochado - Website

Website moderno e responsivo para o restaurante Sabor Arrochado, localizado em Manaíra, João Pessoa - PB.

## 🚀 Características

- ✅ Design moderno e responsivo
- ✅ Integração com WhatsApp
- ✅ Cardápio dinâmico
- ✅ Galeria de pratos
- ✅ Localização com Google Maps
- ✅ Otimizado para SEO
- ✅ Performance otimizada
- ✅ TypeScript
- ✅ Tailwind CSS

## 📋 Seções

- **Hero**: Introdução impactante com CTA
- **About**: História do restaurante
- **Featured Dishes**: Pratos em destaque
- **Menu**: Cardápio completo por categoria
- **Gallery**: Galeria de fotos dos pratos
- **Location**: Mapa e informações de localização
- **Footer**: Links rápidos e contato

## 🛠️ Tecnologias

- React 18
- TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- Google Maps API

## 📦 Instalação

```bash
npm install
```

## 🚀 Desenvolvimento

```bash
npm run dev
```

O site estará disponível em `http://localhost:3000`

## 🔨 Build

```bash
npm run build
```

## 📱 Estrutura do Projeto

```
src/
├── components/       # Componentes React
├── hooks/           # Custom hooks
├── utils/           # Funções utilitárias
├── data/            # Dados estáticos
├── constants/       # Constantes
├── types/           # Tipos TypeScript
├── styles/          # Estilos globais
├── App.tsx          # Componente principal
└── main.tsx         # Entrada da aplicação
```
